# Secure Password Management QA Project

## Overview

This project demonstrates QA activities for a secure password management feature, including requirement analysis, test design, manual test execution, and defect reporting.

## Scope

The project covers:

* Password complexity validation
* Common password rejection
* Password visibility toggle

## QA Activities

* Analyze user stories and acceptance criteria
* Design test cases with positive and negative scenarios
* Execute test cases on a web application
* Document test results and defects

## Project Structure

* Requirements: User stories and acceptance criteria
* Test Design: Test cases and test data
* Test Execution: Execution results and reports
* Defects: Bug reports and analysis

  ## Traceability
  The project maintains traceability between:
- User Stories
- Acceptance Criteria
- Test Cases
- Defects
